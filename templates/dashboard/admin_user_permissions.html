Django Admin Access Control Rules
  • Admin Login Access Requirement: A user must have is_staff = True and is_active = True to access the Django Admin console at /admin/ and the Admin Dashboard.
  • Superuser Access (is_superuser = True): Has all model permissions automatically without explicitly assigning permissions.
  • Standard Customers: Have is_staff = False, allowing them access only to the Customer Dashboard, Product Catalog, and Checkout.
  • Audit Logs Protection: OrderLog is configured as read-only in the Admin site to ensure database trigger audit integrity.
