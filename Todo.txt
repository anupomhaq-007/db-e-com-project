PROJECT OVERVIEW & ROADMAP
--------------------------------------------------------------------------------
This project implements a full-stack E-Commerce Database System adhering strictly 
to CSE 303 Lab requirements (E-commerece-Database-System.docx.pdf). The application is 
built using HTML5, Bootstrap 5 CSS/JS, and Bootstrap Icons (zero React), with Django 5.2 
as the backend connected to a Neon PostgreSQL cloud database.

[x] 1.3 Django Relational Models & Schema Definition (Task-1 Data Dictionary)
    - Category: category_id (PK), name, description.
    - Supplier: supplier_id (PK), company_name, contact_person, phone, email, address.
    - Product: product_id (PK, 101..113), name, brand, price, stock_quantity, description, availability_status, category (FK), supplier (FK).
    - Customer: customer_id (PK), user (OneToOne to auth.User), full_name, email, phone, address, registration_date, membership_level.
    - Warehouse: warehouse_id (PK), warehouse_name, location, storage_capacity.
    - WarehouseStock: warehouse (FK), product (FK), stock_quantity (Many-to-Many Bridge).
    - Order: order_id (PK), customer (FK), order_date, order_status, shipping_address, total_amount.
    - OrderDetail: order (FK), product (FK), quantity, unit_price, subtotal (Weak Entity).
    - Payment: payment_id (PK), order (OneToOne FK), payment_date, amount, tax, discount, final_amount, payment_method, payment_status.
    - OrderLog: log_id (PK), order_id, deletion_timestamp, details.
